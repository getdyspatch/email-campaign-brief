Built for the way email teams actually work

It does more than fill in a template — it pressure-tests your thinking and writes the fiddly bits.

Market research

Pressure-tests your inputs with light web research — competitor sends, audience signals, and benchmarks — so the brief reflects reality, not guesswork.

Recommendations

Offers one to three sharp, research-backed suggestions specific to your campaign — segmentation, layout, or a newer technique — for you to accept or reject.

Sample layout & content

Generates a content-block table — hero, body, CTAs, footer — with directional draft copy tuned to your audience and single-minded idea.

UTM code generation

Builds consistent UTM tracking parameters with sensible defaults from your ESP and campaign name — never an afterthought, always in the brief.

Memory

Remembers your brand, ESP, compliance scope, owners, and output format across sessions, so it never re-asks what you told it last time.

Build email in Dyspatch?

You don't need a Dyspatch account to use this skill — the standard version is tool-neutral and works with any ESP. But if your team produces email in Dyspatch, there's a dedicated variant that grounds the sample layout in your account's real modules and blocks, so the brief references components you can actually drop in.

Install it in Claude

  1. Download the .skill file above (it's a zip archive).
  2. Unzip it into your skills directory — for Claude Code that's ~/.claude/skills/: 
    unzip email-campaign-brief.skill -d ~/.claude/skills/
  3. Confirm the unpacked folder is named email-campaign-brief, then restart Claude so it picks up the skill.
  4. Ask Claude something like “write a brief for my next email campaign” — the skill takes it from there.
